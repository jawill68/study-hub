Recommended Study Path
1
Learn the vocabulary
Start in the Master Glossary. Work one category at a time — Engine, then C#, then Gameplay — and study the code examples closely; they mirror what the certification tests.
2
Drill in Practice mode
Move to the Drill Trainer in Practice mode. Read every explanation, especially on the code-reading questions — understanding why an answer is right matters more than the score.
3
Untangle the look-alikes
Skim Common Confusions once a few mix-ups show up in drilling — Awake vs Start, = vs ==, and Collider vs Trigger are worth locking in early rather than re-confusing on the cert exam.
4
Autopsy the classic bugs
Open the Mistakes Autopsy and study the errors every beginner makes. Recognizing these on sight is a large part of passing a Unity certification exam.
5
Practice writing real code
Work through the Self-Grader's code-writing and design-reasoning prompts. Multiple choice tests recognition — this is the closest thing here to actually writing a script yourself.
6
Test under exam conditions
Return to the Drill Trainer and run a timed Exam Mode session across all categories. Use the per-category breakdown to see exactly where to review.
