Functions & Relations

Master this unit to unlock the concepts that follow

📖 Unit Overview

Functions are the foundation of algebra. A function is a relationship where each input produces exactly one output. In this unit, you'll learn to recognize functions, describe them, and understand how they behave through different representations (equations, graphs, tables, ordered pairs).

Real-World Context: Functions model real-world relationships: temperature over time, distance traveled, earnings vs. hours worked. Mastering functions opens the door to every topic that follows.

🎯 Learning Objectives

By the end of this unit, you'll be able to:

  1. Distinguish functions from relations using multiple representations
  2. Identify domain and range from graphs, equations, and sets of ordered pairs
  3. Evaluate and interpret functions in context
  4. Apply transformations (shifts, stretches, reflections) to parent functions
