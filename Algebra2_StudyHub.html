Quick Reference — Key Formulas
U1 · U3 — FUNCTIONS & QUADRATICS
Avg Rate of Change [f(b)−f(a)] / (b−a)
Axis of Symmetry x = −b / (2a)
Quadratic Formula x = [−b ± √D] / 2a
Discriminant D = b² − 4ac
Vertex Form f(x) = a(x−h)² + k
Completing □ x²+bx + (b/2)² = (x+b/2)²
U2 — POLYNOMIAL FUNCTIONS
Remainder Thm rem = f(c) when ÷(x−c)
Factor Thm f(c)=0 ⟺ (x−c) is factor
Rational Roots ±factors(c₀) / factors(aₙ)
Multiplicity Even→bounce; Odd→cross
FTA degree n → exactly n roots (in ℂ)
Conjugate Pairs a+bi root ⟹ a−bi root
U4 · U5 — RATIONAL & RADICAL
Hole factor cancels from num & den
HA: less deg(num) < deg(den) → y=0
HA: equal y = leading coeff ratio
Rational Exp x^(m/n) = (ⁿ√x)ᵐ
Extraneous always check in original eq.
Domain √ radicand ≥ 0 for even index
U6 — EXPONENTIAL & LOGARITHMIC
Product log_b(xy) = log_b(x)+log_b(y)
Quotient log_b(x/y) = log_b(x)−log_b(y)
Change of base log_b(x) = log(x)/log(b)
Continuous A = Pe^(rt)
Growth base 1 + rate
Decay base 1 − rate
U7 — SEQUENCES & SERIES
Arith explicit aₙ = a₁ + (n−1)d
Arith sum Sₙ = n/2 · (a₁ + aₙ)
Geo explicit aₙ = a₁ · r^(n−1)
Geo sum (finite) Sₙ = a₁(1−rⁿ)/(1−r)
Geo sum (∞) S = a₁/(1−r), |r|<1
Converges when |r| < 1
U8 · U9 · U10 — STATS, CONICS, TRIG
Combo C(n,r) = n!/[r!(n−r)!]
Perm P(n,r) = n!/(n−r)!
Circle (x−h)²+(y−k)²=r²
Ellipse x²/a²+y²/b²=1 (a>b)
Period T = 2π/|B| for A·sin(Bx)
Amplitude |A| in y=A·sin(Bx)+D
Study Strategies
🔁
Spaced Repetition
Review Glossary terms across multiple short sessions rather than one long cram. Star the ones you miss. Space beats mass — every time.
✍️
Active Recall
In the Glossary, expand a term and cover the definition. Try to recall it from the term name alone. The struggle to retrieve is what builds retention.
⚠️
Error-First Studying
Read the Mistakes Autopsy and Common Confusions before attempting Tier 3 questions. Know the traps before you walk into them. Memory Locks first.
⏱️
Timed Practice
Use Speed Drill or Exam Mode in the Drill Trainer. Algebra 2 exams are time-pressured. Train under conditions that match the test environment.
📊
Target Weak Units
After each session, check the unit mastery bars. Any unit below 70% goes back to Build 1 and Build 3 before retrying. Don't skip over the pain points.
🔗
Use the Sequence
Glossary → Graph Lab → Drill Trainer → Autopsy & Confusions → Self-Grader → Exam Mode. Each build makes the next one more effective. Don't skip to the end.
Suggested 4-Week Study Schedule
WEEK 1
Master Glossary — U1 through U5
Read definitions and use the Flashcard Quiz to self-test. Open the Graph Lab for every function family you meet. Daily: 20–30 minutes.
📖 Build 1
WEEK 2
Drill Trainer — Tier 1 & 2, U1–U5
Complete all Tier 1 questions first. Hit 70%+ per unit before unlocking Tier 2. Use Show-Work Mode. Note every miss for Autopsy review.
⚡ Build 2
WEEK 3
Glossary U6–U10, All Autopsies, Tier 3
Finish the Glossary. Work the Autopsies and run Speed Sort in Common Confusions until you hit 90%. Then attempt Tier 3 questions.
🔬 Build 3
WEEK 4
Exam Mode — Daily, Target 80%+
Run Exam Mode daily and do 2 Self-Grader prompts on paper. Re-study any unit below 70% on the mastery bars before each retry.
